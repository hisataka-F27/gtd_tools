# スモークチェックリスト（毎フェーズ実行）

`test/fixtures/golden.json` を「読み込み」した状態から確認する。

- [ ] 起動して赤いエラーバーが出ない / 右下「自動保存 有効」表示
- [ ] 収集: テキスト入力 → Enter → 収集トレイに入る
- [ ] 明確化: 収集トレイの項目をクリック → 質問フロー → 次のアクション/待ち/カレンダー/いつか/資料 の各分岐で保存できる
- [ ] 一覧: チェックで完了 → 再度クリックで復帰
- [ ] 編集パネル: 状態・コンテキスト・所要時間・期限・担当・プロジェクトを変えて保存 → 一覧に反映
- [ ] 削除: 項目 / プロジェクト / コンテキスト の各削除で確認ダイアログが出て、正しく消える
- [ ] コンテキスト: 追加・改名（使用中の項目が追従する）・並べ替え・削除
- [ ] プロジェクト: 一覧表示・行動追加(Enter)・完了・削除（行動は残り所属だけ外れる）
- [ ] 定型: 新規作成 / daily・weekly・monthly・adhoc の表示 / 単発投入 / 一括投入 / 編集 / 削除
- [ ] 絞り込み: 所要時間チップ・エネルギーチップ・検索(`/`)
- [ ] 週次レビュー: 開始 → 全ステップ送り → ジャンプ → 完了（最終レビュー日が更新される）
- [ ] キー操作: `n` で収集欄、`/` で検索欄、`Esc` でパネル/レビューを閉じる
- [ ] 書き出し → 別プロファイル/シークレットで読み込み → 同じ状態が再現する
- [ ] リロード後もデータが残っている（localStorage 保存が生きている）
- [ ] 記号入り（`<>&"'`）のタイトルが崩れず表示される
- [ ] ウィンドウ幅を狭めてレイアウトが崩れない
- [ ] 一覧のスクロール（#14）: 幅 1200px 以上で「次のアクション」を 40 件以上にする
  - [ ] 一覧を下までスクロールして一番下の行をクリックしても、ページ自体はスクロールせず、右パネルの「行動 / 内容」が画面内に見える
  - [ ] 行を選んでも一覧のスクロール位置が先頭へ跳ばない
  - [ ] ビューを切り替えると一覧は先頭から表示される
  - [ ] 幅 700px でも、行を選ぶとパネルが全画面でかぶさり、編集できる
  - [ ] `j`/`k` でカーソルを一番下まで動かすと、カーソル行が一覧の中で見えている
- [ ] プロジェクトの既定コンテキスト（#15）
  - [ ] 収集した項目を明確化 →「プロジェクト」で作ると、選んだ「その一手のコンテキスト」がプロジェクト編集パネルの「既定のコンテキスト」に入っている
  - [ ] 既定のコンテキストを選んで保存し、「次の一手を追加」から足した行動にそのコンテキストが入る（ラベルにも `（@PC）` のように出る）
  - [ ] 既定が「未設定」なら、従来どおりコンテキストなしで足される（ラベルは `（コンテキスト未設定）`）
  - [ ] 既定を後から変えても、すでに足した行動のコンテキストは変わらない
  - [ ] 古いデータ（`context` を持たないプロジェクト）を読み込んでも赤いエラーバーが出ない
- [ ] 「今日やる」の並べ替え（#13）
  - [ ] 「次のアクション」で `t` を押して5件に印を付け、「今日やる」を開く。行の左につまみ（⠿）、右に ↑↓ が出る（他のビューには出ない）
  - [ ] 3番目をつまんで先頭へドラッグすると並びが変わる。リロードしても保たれている
  - [ ] `Cmd/Ctrl+Z` で並びが戻る
  - [ ] ↑↓ ボタンでも同じように動く。先頭の ↑ と末尾の ↓ は無効（押しても動かない）
  - [ ] 行の本体をクリックすると、これまでどおり編集パネルが開く（並べ替えにならない）。↑↓ を押しても編集パネルは開かない
  - [ ] 検索欄に文字を入れると、つまみと ↑↓ が消え、「絞り込み中は並べ替えできません」と出る
  - [ ] ★を外して付け直した項目は末尾に付く
  - [ ] 翌日（`flagged` を手で書き換える等）は「今日やる」が空になり、新しく印を付けたものは末尾から並ぶ
  - [ ] `j`/`k` の移動順が画面の並びと一致している

## 判定方法

赤いエラーバーの有無は目視だけでなく、ブラウザの開発者コンソールで
`document.getElementById("errBar")` を評価して `null` であることを確認すると確実。
